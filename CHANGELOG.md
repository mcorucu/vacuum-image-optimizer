# Changelog

## 1.2.0

- Added automatic frontend delivery with AVIF -> WebP -> original fallback.
- Added source-aware derivative registry and responsive registered-size generation.
- Added cache-aware `Accept` negotiation, fallback diagnostics, and reversible delivery settings.

## 1.1.0

- Added WordPress 7.0 compatibility metadata and PHP 8.3 readiness hardening.
- Expanded System Status diagnostics and added a path-safe Copy Diagnostics report.
- Moved automatic upload optimization to the attachment-metadata stage; Safe Mode queues work conservatively.
- Added bulk scan-all, safe cancel-pending, retry-failed, clear-failed, resume state, remaining, batch-size, and elapsed-time controls.
- Expanded the CSV report with source status, generated-format filenames and states, and safe error/skipped reasons.
- Improved automatic optimization states in the Media Library.
- Documented local-only image processing and data handling.

## 1.0.1

- Added setup, expanded format support, safer defaults, and improved status feedback.

## 0.9.0

- Initial public release.
